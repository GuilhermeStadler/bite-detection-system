Dúvidas frequentes

O que é o Bite Detection System?

O Bite Detection System é uma plataforma que utiliza Inteligência Artificial para auxiliar na identificação de acidentes envolvendo animais peçonhentos. O sistema analisa imagens e sintomas informados pelo usuário para apresentar possíveis resultados, níveis de gravidade e orientações iniciais.

O sistema substitui atendimento médico?

Não. O Bite Detection System é uma ferramenta de apoio inicial e não substitui avaliação médica profissional. Em casos graves ou suspeitos, a recomendação é procurar atendimento médico imediatamente.

Como a análise é realizada?

A análise é feita a partir das informações enviadas pelo usuário, incluindo imagem da lesão ou do animal, sintomas apresentados, tempo desde o acidente, localização da picada, cidade e estado do ocorrido. A Inteligência Artificial combina essas informações para gerar uma estimativa dos possíveis animais relacionados ao acidente.

Quais animais fazem parte do projeto?

O sistema foi desenvolvido para reconhecer acidentes envolvendo diferentes espécies de importância médica no Brasil, incluindo aranhas, escorpiões e serpentes peçonhentas.

O sistema funciona apenas com imagens?

Não. Além da imagem, o Bite Detection System também utiliza os sintomas descritos pelo usuário para tornar a análise mais completa e aumentar a precisão dos resultados.

O sistema indica hospitais próximos?

Sim. O sistema possui integração com localização e mapas, permitindo identificar hospitais e unidades de saúde próximos ao usuário para facilitar o atendimento rápido em situações de emergência.

O sistema apresenta nível de gravidade?

Sim. A plataforma foi desenvolvida para apresentar estimativas de gravidade com base nos sintomas e características informadas durante a análise.

O projeto pode ajudar pessoas em áreas rurais?

Sim. Um dos principais objetivos do Bite Detection System é auxiliar pessoas em regiões afastadas, onde muitas vezes existe dificuldade em identificar rapidamente o animal causador do acidente.

Como os dados do projeto foram organizados?

Os dados utilizados no desenvolvimento foram organizados a partir de materiais científicos, informações públicas de saúde e imagens de referência.

O Bite Detection System ainda está em desenvolvimento?

Sim. O projeto continuará recebendo melhorias relacionadas à Inteligência Artificial, expansão do banco de dados, novas funcionalidades e aprimoramentos da plataforma.
